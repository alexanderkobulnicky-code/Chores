CHORES APP — VERSION 2

Changes:
- Each task now has a Recurrence setting.
- Scheduled: keeps an established cadence; doing a task early advances to the next scheduled cycle instead of moving the clock.
- Since completion: restarts the interval from the moment you mark the task done.
- Existing saved tasks migrate to Scheduled automatically.
- Existing local data uses the same storage key, so task settings and streaks remain available.
- Service-worker cache updated so the new app can replace the old cached version.
